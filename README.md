# ✏️ なぞりっこ

文字や線を**ゆびで なぞると、ふうせんが われたり、ほしが ひかったり**する、特別支援教育向けの なぞり教材アプリです。
iPad の Safari で開くだけで使えます（ログイン・インストール不要）。

## なぞると どうなる？（7しゅるい＋おまかせ）

| | テーマ | なぞると… |
|---|---|---|
| 🎈 | ふうせん | 文字の形に ならんだ ふうせんが「パン！」と われる |
| 🫧 | シャボンだま | シャボン玉が はじける |
| ⭐ | ほし | グレーの ほしが 金色に ひかる（ドレミの音） |
| 🌸 | おはな | めが 出て、花が さく |
| 🍎 | くだもの | くだものが かごに とんでいき、数が ふえる |
| 🌈 | にじいろ | なぞった ところが にじ色に ぬられていく |
| 🎹 | ピアノ | なぞるたびに ドレミ…と 音が なる |

## なにを なぞる？（モード）

せん・かたち（たて・よこ・ななめ・まる・さんかく・しかく・なみなみ・ギザギザ・ぐるぐる など）／ひらがな／だくおん／はんだくおん／ようおん／カタカナ／カタカナ てんてん・まる／すうじ／ABC／abc／じぶんで（先生が ことばを 入力）

## 使い方（先生）

- 右上の ⚙️ を **1.5秒ながおし** で先生用せってい。
  - クリアに必要な割合（やさしい 3/4・ふつう 9割・ぜんぶ）
  - あたりの広さ（手先の操作が難しい子は「ひろい」）
  - おてほんの文字（こい・うすい・なし）、書体（教科書体・まるもじ）
  - 順番／ランダム、できたら自動で次へ、演出ひかえめ、音声・効果音
  - 「じぶんで」モードの ことば（なまえ・今日の ことば など）
- できた文字には ✔ がつき、ホーム画面に進み具合が表示されます（その iPad に保存）。
- ※ 書き順は判定しません（どこから なぞっても OK）。

## しくみ

文字をフォントで描き、細線化（Zhang-Suen）して「なぞる道」を自動で求め、その上にふうせん等を等間隔に並べています。
そのため、どんな文字・ことばでも同じように遊べます。効果音はプログラムで合成しているので音声ファイルは不要です。
